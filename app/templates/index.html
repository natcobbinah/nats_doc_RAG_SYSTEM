Retrieval Augmented Generation for Production Documents

Nats RAG System ingests multi-format files, extracts structured text, computes BERT embeddings, stores vectors in Chroma for fast retrieval, and serves preview-ready assets with Google Drive file and thumbnail storage.

Pipeline Stages

  • File ingestion from supported formats and source connectors.
  • Content extraction and language detection with normalized page metadata.
  • Embedding generation using BERT and indexing into Chroma collections.
  • Semantic retrieval and result composition for question answering workflows.

Storage and Preview Layer

  • Original files are uploaded to Google Drive for durable access and sharing.
  • Thumbnails are generated per file type and uploaded to a dedicated Drive folder.
  • Drive URLs are attached to metadata to support frontend preview experiences.
